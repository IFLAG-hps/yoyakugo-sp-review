# 予約GO 管理画面（B画面）スマホ対応モック レビュー

開発部から共有された「B画面(管理画面)フレキシブル対応」一式を、
iPhone 相当の 390px 幅とタブレット幅（768 / 900 / 1024px）で実際に描画して確認した記録です。

- 公開ページ: https://iflag-hps.github.io/yoyakugo-sp-review/
- 対象: B画面(管理画面)フレキシブル対応 / 全31画面
- 確認日: 2026-08-26

指摘は「要修正（不具合）」「要検討（UX設計）」「細かい指摘」の3段に分け、
主な指摘には 390px で撮影した画面キャプチャに赤枠と吹き出しを添えています。
